# HyReady-GA Hydrogen Readiness Digital Twin MVP

HyReady-GA is a React + TypeScript + Vite stakeholder demonstrator for interactive, simulation-only hydrogen readiness analysis on a simplified airfield model.

## Disclaimer
**This MVP uses simulated data for demonstration purposes only and does not represent certified safety analysis or regulatory approval.**

## Features
- Interactive sensor placement for Hydrogen, Thermal, Proximity, Pressure, and Weather sensors.
- Real-time scenario controls: tank location/size, leak severity, wind speed/direction, traffic intensity, time of day.
- Timeline replay slider to scrub simulated history and refresh sensor outputs.
- Dynamic heatmap layers (hydrogen/thermal), with on/off toggle and opacity control.
- Alert panel with plain-English messages and configurable hydrogen + thermal thresholds.
- Scenario save/compare cards with autogenerated Markdown report content.
- Natural language summary explaining risk and demand impacts.
- Data-flow visualization: Sensor Input → Validation → Model → Output.
- Sidebar pages for Dashboard, Simulation, Demand Forecasting, Risk Assessment, Reports.

## Architecture (Extensible)
- `src/lib/simulationEngine.ts`: typed simulation logic for sensor readings, heatmaps, alerts, safety zones, risk score, demand proxy.
- `src/types/sensors.ts`: TypeScript domain models for sensors, controls, outputs, saved scenarios.
- `src/lib/scenarios.ts`: scenario persistence helpers and report generation helper (Markdown).
- `src/pages/SimulatorPage.tsx`: UI orchestration and in-browser simulation state.

## Simulated now vs planned next
### Simulated now
- In-browser state management (no backend).
- Simplified physics-inspired calculations using proximity, wind direction, traffic, leak level, and random noise.
- Safety overlap checks against mock hangar positions.

### Planned future integration
- Replace synthetic equations with validated engineering dispersion/thermal models.
- Bind to real telemetry pipelines (IoT, SCADA, weather feeds).
- Add persistence, collaboration, authentication, and auditable scenario history.
- Add PDF export and formal regulatory evidence workflows.
